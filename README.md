🚗 Electric Vehicle (EV) Data Analysis

📌 Overview
This project explores Electric Vehicle (EV) data to find adoption trends, usage patterns, and charging station needs.

🛠️ Tools Used
Python (Pandas, Matplotlib, Seaborn)
Jupyter Notebook

📈 Key Insights
EV adoption is growing year by year.
Some states lead in EV registrations.
Availability of charging stations strongly impacts adoption.
